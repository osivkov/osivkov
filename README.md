A project bringing together frontend development, backend services,
real-time communication, persistent data, and containerized deployment.

**Stack:** React · Vite · TypeScript · Node.js · Express · Socket.IO ·
PostgreSQL · Prisma · NGINX · Docker Compose

- React frontend connected to a TypeScript backend.
- Real-time communication through Socket.IO.
- PostgreSQL persistence with Prisma ORM and migrations.
- Containerized services behind an NGINX reverse proxy.
- API documentation with Swagger and AsyncAPI.
- Monitoring and alerting components.

**What it taught me:** how application components fit together,
and how infrastructure decisions affect development and troubleshooting.
